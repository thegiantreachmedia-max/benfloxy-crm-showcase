# BenFloxy CRM

**A customer and lead management CRM built for BenFloxy Services.**

This repository is a showcase. Source code is private.

## Who it's for

BenFloxy CRM is built for the team at BenFloxy Services who manage customer relationships and sales leads. It provides a dedicated system for organising customer information and managing leads in one place.

## Key features

- **Lead tracking** - Keep track of leads throughout the customer acquisition process.
- **Customer records** - Maintain organised customer information in one system.
- **Central workspace** - Manage customers and leads from a single CRM.

## Tech stack
- JavaScript
- Supabase
